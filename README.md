# Heroes Prototype

Браузерный мультяшный шутер от третьего лица в духе Battlefield Heroes. Свой low-poly стиль, весь арт собран из примитивов прямо в коде.

![Взрыв гранаты](docs/explosion.png)

## Запуск

```bash
npm i
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173), и кликни по экрану.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | бег |
| Пробел | прыжок |
| Мышь | камера |
| ЛКМ | стрельба |
| R | перезарядка |
| Q | граната |
| Esc | пауза |

## Что внутри

- `src/world.js` — карта-городок: дома, вышка, ящики, мешки с песком, деревья, стены по краям
- `src/soldier.js` — солдат из коробок с анимацией бега, прыжка и прицеливания
- `src/player.js` — управление, камера из-за плеча, тряска камеры
- `src/physics.js` — простая физика: гравитация и столкновения с AABB
- `src/bots.js` — боты-мишени: бродят по карте, получают урон, отлетают и респавнятся
- `src/grenade.js` — граната с отскоками и фитилём
- `src/effects.js` — взрыв (огненный шар, ударное кольцо, дым, обломки, «БАХ!»), трассеры, искры, цифры урона
